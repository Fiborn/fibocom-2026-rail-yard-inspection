# 巡检平台硬件清单

本目录用于整理“铁途灵探”铁路货场空地一体智能巡检平台的硬件组成、结构资料、PCB 资料和物料清单。表格化清单见 `bom.csv`。

## 四旋翼无人机载平台部分

| 序号 | 硬件 | 作用 |
| --- | --- | --- |
| 1 | Pixhawk2.4.8 飞控 | 整机主控，运行 PX4 固件，负责姿态解算、电机调度和外设串口管理；外接 GPS 定位模块、蜂鸣器和安全开关。 |
| 2 | 4-in-1 四合一电调 | 驱动无刷动力电机，集成 BEC 供电。 |
| 3 | 无刷动力电机 | 无人机飞行动力执行元件。 |
| 4 | FFY 航模锂电池 | 多 S 航模动力锂电，作为整机主电源；标签提示最大 5C 充电，长期保存 3.8V 单节。 |
| 5 | Waveshare ST3215 串行总线舵机 | 云台舵机，用于摄像头俯仰、旋转和巡检镜头姿态调节。 |
| 6 | 图传模块 | 黑色多路端子盒，板载 4R7 功率电感；用于模拟视频传输和机载图像回传地面。 |
| 7 | ESP32-S3 拓展底板 | 机载协处理器，拓展 IO，管理继电器、外设传感器，并与 Pixhawk 串口通信。 |

## 地面巡检小车平台部分

| 序号 | 硬件 | 作用 |
| --- | --- | --- |
| 1 | Arduino Nano 主控板 | 小车运动控制核心。 |
| 2 | JGB37-520 直流减速电机（DC12V） | 小车行走驱动电机，带编码器。 |
| 3 | 电机驱动模块（红色双 H 桥） | 控制直流减速电机正反转和调速。 |
| 4 | 5V 单路继电器模块 | 开关量控制车灯和外部负载通断。 |
| 5 | 钥匙电源锁开关 | 小车整机电源机械锁。 |
| 6 | 绿色封装电源稳压盒 | 小车电源降压供电单元，为板卡和传感器供电。 |
| 7 | 超声波测距传感器 | 小车避障距离检测。 |
| 8 | LED 大功率探照灯 | 巡检补光照明。 |
